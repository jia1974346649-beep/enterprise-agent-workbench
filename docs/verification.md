## 可重复的基础命令

在仓库根目录运行：

```bash
python --version
python -m unittest discover -s tests -v
python -m workbench --port 8765
```

最后一条命令启动服务后，在浏览器打开 [http://localhost:8765](http://localhost:8765)。健康检查接口为 `GET /api/health`。

本次自动化测试还使用了 `python -B -W error::ResourceWarning -m unittest discover -s tests -v`。测试耗时只反映本机验证过程，不作为性能基准。

## 发布快照检查

`publication-manifest.json` 列出允许公开的文件与 SHA-256；清单自身不进行循环自哈希。运行以下命令可复核当前文件与可达 Git 历史：

```bash
python scripts/audit_public_package.py --root . --git-history
```

发布前还使用了仓库外的私有关键词列表检查公司与人员标识，该列表不随作品公开。脚本核对文件清单、哈希、凭据与联系方式模式、路径和 Git 元数据；PNG 另核对结构、元数据和尾随内容，并人工查看像素画面。测试中的少量禁止地址为精确列出的负向用例，私有关键词检查不受这些例外影响。

公开截图仅为本仓库的合成演示界面；没有使用原企业截图。模式检查与人工检查支持本次已审查快照，不构成绝对匿名保证。

## 应覆盖的行为

| 范围 | 关键观察与断言 |
|---|---|
| 输入与工具参数 | 非法结构、超限输入和未知工具不会进入任意执行 |
| 查询与引用 | 查询只返回当前租户材料；引用来自实际返回的文档 |
| 角色权限 | 只读身份写入被服务端拒绝 |
| 租户作用域 | 文档、任务和审计记录不能越过租户边界；所有者查看本租户审计，其他角色仅查看自己 |
| 写入前审批 | 发起请求后没有提前创建任务 |
| 审批绑定 | 身份、租户、工具和参数与原请求一致；不存在或跨身份的审批统一返回 404 |
| 拒绝、过期与重复确认 | 拒绝或过期不写入，重复确认不重复创建 |
| 重置 | 仅所有者能重置当前租户的演示状态 |
| 失败路径 | 错误结果明确，步骤可查看，不能伪装执行成功 |
| 默认离线运行 | 无模型账号可以启动，不依赖外部运行时请求 |
| 页面可用性 | 身份切换、执行、审批与结果展示能完成演示路径 |

测试文件应以行为为断言对象。测试名称与覆盖范围可以辅助阅读，但不能代替运行结果。

## 可选模型接入的验证口径

如提供可选本地模型模式，应分开记录：

1. 协议和失败处理测试，可使用本机模拟服务复现。
2. 真实模型连接测试，需要记录实际运行条件。
3. 任务效果评估，需要明确样本、指标与失败样例。

模拟服务测试不能写成“真实模型推理通过”。没有实际执行的模型效果不写入成果数字。

## 公开前检查

- 只提交独立重建的演示代码与合成数据。
- 不包含原公司代码、数据库、业务文档、真实人员和客户信息。
- 不包含原始截图、部署信息、凭证、原仓库历史和本机路径。
- 检查文件内容、文件名、二进制附件及 Git 作者信息和可达历史。
- 检查 README、协作分工与演示能力是否一致，避免把计划或协议测试表述为已完成的生产能力。

检查结果只支持已检查版本与范围，不构成绝对匿名或所有第三方权利的保证。
